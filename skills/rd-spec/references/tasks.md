# 001 <功能名> 任务清单

勾选时把验证证据写进括号里；没做的标「未做：原因」并写进交付报告。

- [ ] T1 定位现状并记录证据（AC-0：读代码 / 跑命令 → 结论）
- [ ] T2 <第一条改动>（AC-1：命令 → 结果）
- [ ] T3 <第二条改动>（AC-2）
- [ ] T4 补测试：覆盖 AC 里的每条判定（AC-1、AC-2）
- [ ] T5 跑全量校验并留输出（`npm test` → `# fail 0`）
- [ ] T6 交付报告 + 关闭 Issue（AC 表逐条填结果）

## 规则

- 一条任务只做一件事，能被单独验证；做不到就拆。
- 每条任务都挂到至少一个 AC；挂不上的任务不是本规格的一部分。
- 执行中发现新任务，先回 spec 补 AC，再加进清单。
