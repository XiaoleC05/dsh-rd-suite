# 改进提案

每次复盘生成一个文件：`YYYY-MM-DD.md`；技能沉淀草稿用 `skill-<名称>.md`。提案只是建议，经用户批准后才应用（见 skills/rd-retro/SKILL.md）。

## 提案格式
```
## P<序号>｜<一句话标题>｜等级 C1 / C2 / C3｜状态：待批准 / 已批准 / 已拒绝 / 已应用（版本号）
- 问题：
- 证据：指标数值、与上期对比、涉及的会话数
- 改动：文件路径 + diff
- 预期影响：KPI 编号与幅度
- 风险：
- 回滚：
```

## 规则
- 每次最多 3 条，按影响排序。
- 没有证据的猜测不写成提案，可以写进“观察”一节，下期继续收集数据。
- 宪章改动优先放在 persona 的 suffix；prefix 的改动要说明为什么不能放进 suffix。
