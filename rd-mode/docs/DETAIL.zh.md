# 研发模式

面向编程、测试、网站、数据与 AI/Agent 研发的一组 Agent 预设。

## 包含的模式
- **研发模式（rd）**：主模式。每个任务先分级（L0 问答、L1 微改、L2 标准、L3 复杂/高风险），按级别走“规格卡 → 计划 → 实现 → 验证 → 独立验收 → 交付”的流水线；领域标准以技能形式按需加载；上下文约 199k token 时自动压缩。
- **研发·侦察（rd-scout）**：只读侦察员，研发模式的默认子代理，返回 40 行以内的结论。
- **研发·验收（rd-review）**：独立验收员，不带作者上下文，亲自运行检查并给出 PASS/FAIL。也可以直接选它来审查现有改动。

## 怎么用
1. 新建会话时选择“研发模式”，像平时一样描述任务；附上验收标准效果最好。
2. 首次安装或升级后，在本仓库目录新建研发模式会话并输入 `/rd-selftest` 自检。
3. 每周输入 `/rd-retro`（或设置自动化任务）复盘，按提示批准改进。

## 文件
- `preset.patch.yml`：三个预设的声明与宪章文本。
- `skills/`：rd-code-standards、rd-testing、rd-web、rd-data、rd-ai、rd-ecosystem、rd-retro、rd-selftest。
- `docs/DESIGN.md`：完整设计说明；`INIT.md`：安装与维护步骤。
- `evolution/`：KPI 报告、改进提案、能力登记表与变更日志。
